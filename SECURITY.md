# Security policy

## Supported versions

snowglobe is pre-1.0. Only the latest release gets security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue. Use
GitHub's private vulnerability reporting: open the
[Security tab](https://github.com/luizribeiro/snowglobe/security) of the
repository and click "Report a vulnerability".

Include the snowglobe version, what an attacker can do, and the steps to
reproduce it.

## Security model

What snowglobe trusts, and what the deploy user can do on a host, is
described in the [security model](https://l9o.dev/snowglobe/security/).
