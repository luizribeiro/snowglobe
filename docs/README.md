# snowglobe documentation

These pages are the source of the snowglobe documentation site,
[l9o.dev/snowglobe](https://l9o.dev/snowglobe/), which renders them with
their navigation and links. Read them there.

Each page is Markdown with front matter for the site: `title`, the sidebar
`group` and its order (`weight`), and a `description`. Links between pages
use the site's paths, such as `/snowglobe/phases/`, so they work on the site
rather than on GitHub. `demos/` holds the recordings the pages show, and
`demos.md` lists them all; neither README.md nor demos.md is part of the
site.
